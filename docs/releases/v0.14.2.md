# v0.14.2 · 控制台全页面加载提速

## 性能优化

- 登录后立即呈现导航与页面控件，仪表盘、游乐场、分组、账号、密钥、服务提供商、日志和设置页按需获取数据，不再等待全部管理接口完成才显示页面。
- 按页面拆分 JavaScript，图表与 Markdown 渲染器延迟加载；首屏 JavaScript 从约 760 kB 降至 276 kB（未压缩）。
- 引入登录会话独立的内存缓存、请求合并和定向刷新。切换页面复用短期缓存；写入后刷新相关资源；退出登录取消旧请求，不跨登录共享数据。
- 管理列表每页渲染 50 行，减少大量账号、分组和密钥造成的卡顿；复用格式化器、分组计数和索引。
- 静态 JavaScript/CSS 预生成 gzip，带内容哈希的资源使用长期缓存；HTML 不缓存，降低升级后旧入口问题。
- 新增可选轻量查询：`/api/keys?usage=false`、`/api/profiles?summary=true`、`/api/stats?recent=false`；保留原有默认响应。优化密钥用量聚合与统计查询，减少重复日志扫描和不必要的数据传输。

## 测试环境下的性能对比

下表来自 Chromium 生产构建，API 固定模拟延迟 240 ms，各运行三次取中位数；并非线上速度承诺。

| 指标 | v0.14.1 | 本次优化 |
| --- | ---: | ---: |
| 仪表盘控件可用 | 1.35 秒 | 0.60 秒 |
| 仪表盘数据可见 | 1.35 秒 | 0.84 秒 |
| 首屏必需请求 | 8 | 2 |
| 账号页返回分组页（缓存有效） | 278 ms / 6 个请求 | 9 ms / 0 个请求 |

另一次真实后端测试中，选择器响应由 2,973,101 字节降为 17,326 字节。

## 兼容性与升级

- 这是完整应用的正式版本，不是 `v0.14.2-console.1` 的独立补丁包。正式标签包含服务端、前端、Docker 构建与升级器所需文件，版本号统一为 0.14.2。
- 保留现有策略目录、模板正文、模型映射、协议转发、账号、密钥及已保存配置；不删减原有功能，不变更数据库结构。
- 继续使用现有控制台系统更新或 Docker 部署流程。升级前备份完整数据卷及主密钥；回退时使用 v0.14.1 完整应用与原有数据，建议先在副本验证。
- 纳入前端缓存与构建回归测试、Rust 静态资源及轻量 API 测试；正式发布以同一提交的完整 CI（含 Docker 构建、替换与回滚验证）通过为准。
