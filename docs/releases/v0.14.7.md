# v0.14.7

## 按模型自动选择策略

- 删除密钥编辑器内“添加冷咖啡策略模板”展开区、模板下拉框和应用按钮。用户只需搜索并勾选需要开启的模型，然后保存。
- 每个实际模型只显示一个勾选项，名称下方用小字显示实际策略来源，由后端统一选择对应策略和模板，不再由前端生成模板绑定 ID。
- 新增模型选择接口与 `strategy_models` 保存字段。仅接受所属分组内已启用且可用账号的实际模型；未知家族且没有已有绑定的模型不可勾选，后端也拒绝保存。
- 保留这把密钥已有的来源及手动绑定。新增选择优先使用固定模型策略，来源重叠时优先冷咖啡；没有固定条目时按家族匹配模板。支持大小写及提供商命名空间，实际注入仍按完整原始模型 ID 精确匹配。
- 寒霜等历史多模型策略拆分为单模型绑定，取消一个名称不会影响另一个。旧固定 ID、旧冷咖啡绑定及旧 `profile_ids` API 继续可用。
- 加载模型失败时禁止保存空选择并提供重试；切换分组仅保留交集。账号、提供商及密钥更改会刷新模型选项缓存。

## 保持不变

- 策略按密钥独立配置；新密钥不自动勾选模型，默认策略关闭。
- 无需口令，不注入欢迎语、激活页或社群广告。默认策略开关与各独立来源正文保留。
- 管理员密码接受任意长度的非空字符串；实际宿主端口仍使用 `ZAKO_PORT`，不是 `PORT`。
- 所有模型效果标记仍为 `unverified`。自动匹配和请求注入验证不代表在线模型效果或破甲成功率。

## 验证与升级

新增后端分类、历史来源保留、别名拆分、密钥隔离、持久化和非法选择测试；请求转发测试覆盖自动选择后四种协议与流式响应。前端增加勾选状态及模板入口移除回归测试。

按现有源码流程更新，保留 `.env`、数据卷与 Compose 项目名，重新构建代理及更新器；运行 `python3 scripts/check-release-version.py --running` 确认二者均为 `0.14.7`。升级前备份 `/data` 和 `.env`，不要执行 `down -v`。
