# v0.14.5 · 管理安全与维护修复版

基于并已发布到 `main` 的 v0.14.4。代理仍按原请求透传，保留现有模型与模板标识；本版不包含策略正文。

## 修复

- 管理员首次初始化、修改密码支持任意非空密码长度。移除前后端 12 字符最小值、256 字符最大值和 1024 字节上限；更新操作的当前密码复核不再限制长度。空密码仍被拒绝。
- 安全入口及 `X-Console-Path` 统一忽略尾随斜杠，避免 `/entry` 与 `/entry/` 被识别成不同入口。
- 保存入口后若地址改变，使用完整页面替换导航到新入口；关闭入口后回到 `/`。
- 恢复 CI 工作流，覆盖 Rust 格式/Clippy/测试、前端测试与构建、Compose/Docker 冒烟，以及管理入口和短/长密码路径。

## 配置说明

- `.env.example` 不定义宿主机端口；当前仓库也没有本地 `.env` 文件。
- `ZAKO_PORT` 在 Compose 中确实控制宿主机映射端口，继续保留。它不会改变容器内应用的 `1990` 监听端口。普通 `PORT` 变量不被应用或 Compose 使用。
- 本版基于 v0.14.4 的 source-maintenance 形态，不携带或注入策略正文。

## 验证

- CI 的 Rust Quality、Backend Tests、Frontend、Docker 全部通过后再发布正式版。
- 回归测试覆盖首次管理员设置短密码、长 Unicode 密码修改与登录、安全入口启用/切换/关闭、入口尾斜杠、根路径隐藏和系统更新密码复核。
