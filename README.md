# 控制台加载提速预览 · v0.14.2-console.1

这是 **v0.14.1 的控制台补丁**，不是完整服务端发行版。包含登录页和八个管理页面的按需加载、会话内请求合并、列表分页、静态资源预压缩及配套的轻量只读 API。没有数据库迁移，不提供服务端二进制或 Docker 镜像；应用版本号和正式更新通道均保持不变。

## 试用与回滚

- **试用前端**：从本预发布的 Assets 下载 `console-static-v0.14.2-console.1.zip` 和 `SHA256SUMS`。核对 ZIP 的 SHA-256 后，解压到测试实例的一个新目录（入口是 `index.html`）。让该实例的 `WEB_DIR` 指向新目录，保留原目录；回滚时恢复原 `WEB_DIR` 并重启测试实例。不要覆盖数据目录。单独替换静态资源不会启用服务端响应精简。
- **源码补丁**：`console-performance.patch` 对应基线 `v0.14.1`，提交 `8d0dd6995192e183a0d75d81e16fd2f8e47a24c2`。在该提交的干净工作副本根目录运行 `git apply --check /path/to/console-performance.patch`，确认无误后去掉 `--check` 应用。没有其他本地修改时可用 `git apply -R --check`、再用 `git apply -R` 撤销同一份补丁。
- `SHA256SUMS` 列出上述两份附件的 SHA-256。GitHub 自动生成的 Source code 归档只包含补丁、校验清单、许可证、说明和本预览的校验工作流，不是整个应用，也不是预编译前端包。

## 性能对比

以下为基线与完整控制台补丁的生产构建在 Chromium 中测得的结果。API 固定模拟延迟 240 ms；耗时取各三轮中位数，不是线上延迟承诺。

| 指标 | v0.14.1 | 控制台补丁 |
| --- | ---: | ---: |
| 仪表盘控件可用 | 1.35 s | 0.60 s |
| 仪表盘数据可见 | 1.35 s | 0.84 s |
| 首屏必需请求 | 8 | 2 |
| 从账号页返回分组页（会话缓存有效） | 278 ms，6 个请求 | 9 ms，0 个请求 |
| 首屏 JavaScript（未压缩） | 760 kB | 276 kB |

在另一次真实后端测试中，选择器响应由 2,973,101 字节降至 17,326 字节；这项变化需要服务端补丁。会话缓存只在内存中保存，不跨登录共享，写入后只刷新受影响的数据。
