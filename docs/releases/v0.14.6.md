# v0.14.6 · 全来源策略恢复与注入修复

## 策略

- 恢复 51 个固定策略 ID 和 16 个冷咖啡模板的正文加载及请求注入。移除打包时的空策略覆盖和 `source-maintenance` 强制开关，源码与镜像使用同一实现。
- 分别恢复冷咖啡、寒霜、kimi-break、AI-Jailbreak、gpt-instruct 和默认策略，独立来源不再被冷咖啡统一替代。DeepSeek 附加 dsh-purge API 上下文适配。
- 冷咖啡所有模板内联工作流、路由、口语归一、6 个父策略和 80 个叶子策略，选择后直接生效，不需要口令；运行时不注入欢迎语、激活页或社群广告。
- 保留历史策略 ID、精确模型别名、每把密钥的独立选择和默认策略开关。映射后的实际模型决定策略，每次请求最多注入一种正文。
- 迁移接受顺序不同但成员完整一致的模型集合，以及尚未附加 DeepSeek 适配说明的旧正文；拒绝重复别名造成的误匹配，明确取消的选择不会被重新启用。

## 管理与配置

- 保留首次初始化、重建管理员和修改密码时任意非空长度的支持，增加长密码初始化、单字符改密、会话失效、重新打开数据库登录及重建管理员回归测试。请求体总大小限制和正常鉴权仍保留。
- `.env.example` 没有无效的普通 `PORT`；旧 `.env` 中该项可删除。`ZAKO_PORT` 仍负责 Compose 宿主机映射，容器内监听保持 `1990`。
- 恢复控制台源码更新可用性；代理与更新器仍从同一版本源码构建。

## 来源与检查

- 为全部来源补齐或恢复本地正文、固定快照、SHA-256、离线导入器和许可说明。gpt-instruct 只声明可验证的项目历史快照，不虚构精确上游提交。
- 自动化检查覆盖所有固定策略与别名、16 个自定义模板、4 类协议、3 类流式响应、实际模型映射、失败重试、未选透传和默认兜底。
- 各独立来源的离线校验会拒绝变化的输入，能够重新生成缺失或损坏的输出；CI 同时检查 Rust、前端和 Docker 镜像。
- 未做真实上游模型效果测试，所有效果状态保持 `unverified`。本次修复确认的是代码路径和实际请求正文，不承诺模型效果或上游供应情况。

## 升级

升级前备份 `.env` 和完整数据目录（包括 `master.key`），沿用原 Compose 项目名和数据卷，不执行 `down -v`。

```sh
git switch main
git pull --ff-only
python3 deploy.py
python3 scripts/check-release-version.py --running
```

固定标签或源码压缩包使用 `python3 deploy.py --local`。代理、更新器、前端及镜像元数据应统一为 `0.14.6`。需要回退时，检出之前的固定标签并以 `--local` 重建两个服务，保留数据卷；恢复备份前先停止对应服务。
